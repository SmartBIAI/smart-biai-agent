# Smart BIAI Agent

基于 **Smart BIAI OpenAPI** 的开源 AI 创作与海外社媒工作台。部署在自己的电脑或服务器上，通过对话查询社媒账号、生成图片和视频、准备发布文案，并在确认后立即或定时发布视频作品。

[在线体验](https://developer.biaibiai.com/smart-biai-agent-static/) · [Smart BIAI 官网](https://www.biaibiai.com/) · [OpenAPI 文档](https://developer.biaibiai.com/docs) · [版本说明](CHANGELOG.md)

在线体验使用模拟数据，无需 API 密钥，记录保存在当前浏览器。自托管工作台支持模拟和真实两种模式，填写自己的 API 凭证即可连接真实服务。

当前版本 **v0.3.2**：优化生成失败原因与悬浮详情、图片生成进度动画和参数确认前的提示顺序；生图每 10 秒、生视频每 15 秒查询结果。支持多轮 Agent、独立登录页、AI 创作与确认发布。详细变化见 [版本说明](CHANGELOG.md)。

## 适合谁使用

- 海外内容创作者：在同一对话中完成创意描述、图片与视频创作、预览和视频发布。
- 品牌与跨境电商团队：上传产品参考素材，制作产品图、海报和短视频，管理已接入的海外社媒账号。
- 开发者：以开源工作台为基础，接入 Smart BIAI OpenAPI，扩展自己的创作与发布流程。

每个部署实例是一个共享工作空间，使用一个管理员访问账号。当前不提供多用户注册、成员权限隔离或租户管理。

## 功能介绍

### BIAI Agent：在对话中接续工作

- **多轮理解**：结合当前对话、草稿、任务实际状态和附件关联，理解省略表达、参数调整与后续操作。
- **查询账号与任务**：按平台、国家、名称或账号 ID 查找账号，查询图片、视频和发布记录。
- **接续创作**：复用当前对话已有提示词、参数和附件；调整模型、时长、画幅、清晰度或图片张数，准备新的报价。
- **保留创作过程**：未确认草稿可以继续编辑；已结束任务的新尝试保留原记录和来源关系。处理中或受理结果不明时，优先查询原任务。
- **附件复用**：直接上传本地图片、视频或音频，图片显示缩略图；可继续使用原附件、替换附件，或引用已完成的生成结果。
- **历史对话**：新建、切换、恢复历史对话。自托管版本将对话和任务保存到服务器，刷新页面后可继续操作。
- **确认执行**：Agent 可以查询、准备草稿和报价；图片生成、视频生成和发布分别由用户在卡片上确认后执行。

真实模式使用 **DeepSeek 或豆包** 规划动作，不要求使用固定指令。离线模拟保留基本流程和按钮演示，完整的自由表达与多轮理解需要配置对话 AI。

### AI 图片生成

- 支持文字生成图片、参考图创作，以及支持蒙版的模型进行局部编辑。
- 可用于产品使用图、产品海报、社媒配图、插画或视频封面创作。
- 支持 GPT Img / GPT Image 和 Banana 系列，模型列表与可选规格由 OpenAPI 动态读取。
- 每任务可请求 **1～8 张**，先查看报价和积分上限，再确认生成。
- 按模型能力选择尺寸、质量、画幅和清晰度；参考图与蒙版数量、格式和大小会校验。
- 对话中查看结果，点击打开大图或原图；可在「发布任务 → 图片记录」查看历史、失败或部分成功结果及结算信息。
- 生成期间显示进度动画，每 10 秒查询结果；失败时显示接口原因，长信息可悬浮或点击展开查看。
- 链接有效期内直接预览，保留期内可刷新结果链接；本应用只保存任务与文件信息，不保存生成图片文件。

### AI 视频生成

- 支持文字生成视频、图片参考、视频参考、音频参考，以及模型允许的组合素材输入。
- 支持 Seedance2.0、Seedance2.5 等系列，按模型能力选择画幅、分辨率、时长和声音。
- 支持具备相应能力的首帧、首尾帧、自动时长及尾帧结果选项，切换模型后重新校验参数和报价。
- 生成前展示报价，确认后创建异步任务，持续更新生成状态。
- 对话与任务详情均可播放视频，生成记录展示模型和时长。
- 生成期间每 15 秒查询结果；失败时显示接口原因，可展开全文或刷新原任务状态。
- 视频直接使用接口返回的地址，封面使用生成结果返回的地址，缺失时留空；本应用不转存生成视频文件。

### 社媒账号管理与视频发布

- 按国家、平台以及名称、别名或 ID 筛选已接入的账号，查看授权状态和账号信息。
- 选择视频后准备发布草稿，人工填写或由 AI 建议标题、描述等内容；可修改后再确认。
- 支持**立即发布**和**定时发布**，预约可选择时区。
- 仅允许授权状态为 **20（已授权）** 且具备发布能力的账号创建发布任务；未授权、授权失败和授权异常账号禁止提交。
- 发布前调用素材记录接口获取视频 ID。该接口只登记视频信息，不上传视频文件，实际素材沿用生成服务地址。
- 查看等待、预约、发布中、成功、失败和待确认等状态；可以取消尚未提交的预约。
- 账号列表、账号作品列表及任务列表固定在各自区域内滚动，首批 20 条，触底每次追加 20 条。

### 连接设置、文件与访问管理

| 功能 | 说明 |
| --- | --- |
| 真实 / 模拟模式 | 模拟模式无需密钥，使用固定图片和约 4 秒的视频素材演示流程；自托管版本两种模式的记录分别保存 |
| Smart BIAI 社媒连接 | 配置 App ID 与 Access Token，用于账号查询和视频发布 |
| Smart BIAI 生成连接 | 配置应用 API Key，共用于图片和视频生成，按应用授权加载模型 |
| 对话 AI | DeepSeek 或豆包二选一，填写 API Key 和已开通的模型 ID |
| 本地参考素材服务 | 上传到自己的服务器，通过公网 HTTPS 域名向生成服务提供限时签名链接 |
| 阿里云 OSS | 与本地文件服务二选一，为选中的参考附件上传并生成限时读取链接 |
| 登录与退出 | 独立登录页、密码显示切换、保持登录 7 天和退出登录；未选择保持登录时会话最长 12 小时 |
| 本地数据 | SQLite 保存对话、草稿、任务和必要媒体信息；API 凭证加密保存，页面不回显完整密钥 |

### 对话 AI 与媒体模型的区别

DeepSeek / 豆包负责理解对话、规划查询、补充文案和准备草稿；**图片与视频由 Smart BIAI 生成 API 执行**。需要分别配置对应密钥。对话模型 ID 由供应商账号的实际开通情况决定，不等同于上述图片或视频模型 ID。

## 从创作到发布

1. **连接服务**：在「连接设置」配置所需的 Smart BIAI 凭证和对话 AI，切换到真实模式。
2. **查找账号**：在对话中查询账号，或在「社媒账号」页按国家和平台筛选。
3. **准备创作**：描述图片或视频目标，可附加参考素材；检查 Agent 整理的提示词、模型和参数。
4. **确认生成**：获取报价，核对积分上限，点击确认后才会提交。生成后直接在对话中预览。
5. **继续调整**：结合当前对话提出修改，或点击「调整参数」。保留未要求改变的内容，再次报价与确认。
6. **确认发布**：视频满意后选择已授权账号，检查标题、描述、封面与发布时间，再确认发布。
7. **跟踪任务**：在「发布任务」查看视频生成、图片生成与发布状态；在历史对话中继续处理。

示例：“查看美国区 TikTok 账号”、“使用参考图生成两张产品使用图”、“把画幅改成 9:16，保留原来的附件”、“基于刚才的视频准备明天上午的发布草稿”。这些是表达示例，真实模式不要求照抄。

## 快速开始

需要 **Node.js 22.13 或更新版本**。

```sh
git clone https://github.com/SmartBIAI/smart-biai-agent.git
cd smart-biai-agent
npm ci
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，选择「模拟模式」即可体验，无需 API 密钥。在 Windows PowerShell 中可使用 `npm.cmd ci` 和 `npm.cmd start`。

本地默认只监听本机。部署到服务器请参阅 [Docker 部署指南](doc/宝塔Docker首次部署.md)，已有实例见 [部署更新指南](doc/更新说明.md)。配置访问账号后，先进入登录页；账号和密码由实例管理员设置，与 Smart BIAI 官网账号分别管理。更新已有部署沿用原账号，无需重新注册。

## 连接真实服务

在「连接设置」填写，也可复制 [环境配置模板](doc/.env.example) 为 `doc/.env.local` 后填写。Docker 使用部署目录中的 `.env`。

| 服务 | 所需信息 | 获取方式 |
| --- | --- | --- |
| Smart BIAI 社媒 | App ID、Access Token、账号查询及发布权限 | [Smart BIAI 官网](https://www.biaibiai.com/) |
| Smart BIAI 生图与视频 | 应用 API Key、相应模型授权与可用积分 | [Smart BIAI 官网](https://www.biaibiai.com/) |
| DeepSeek 或豆包 | 供应商 API Key、已开通的模型 ID，二选一 | 对应供应商控制台 |
| 参考素材服务 | 公网 HTTPS 域名，或 OSS Bucket 与访问凭证 | 自有服务器或阿里云 OSS |

纯文字生成无需准备参考素材文件服务；使用上传附件时，需先配置可被生成服务读取的公网链接。真实生成和对话 AI 调用消耗对应服务额度，费用以实际报价和供应商规则为准。

更多设置见 [使用与配置](doc/部署说明.md)，多轮操作说明见 [Agent 使用说明](doc/Agent使用说明.md)。

## 数据、部署与当前范围

- **自托管**：Node.js + SQLite，支持 Docker 和 HTTPS 子路径部署；前端、接口及后台任务在同一应用运行。
- **生成结果**：本地仅保存任务 ID、模型、参数、视频 / 图片地址、有效期等信息；生成文件仍由上游服务保管，预览受源文件保留期限影响。
- **上传附件**：保存在服务器上传目录；选择 OSS 时，在准备素材时上传选中的文件。不要把数据目录、环境文件或 API 密钥提交到公开仓库。
- **配置与备份**：连接凭证加密保存。备份应包含环境文件、完整数据目录、加密密钥文件和自定义附件目录，具体见部署指南。
- **排期运行**：预约发布依赖应用持续运行；页面关闭不影响服务器继续处理已确认任务，实际发布时间取决于平台处理进度。
- **访问范围**：管理员账号可访问该实例全部对话、任务和设置；登录凭证通过 HttpOnly 会话 Cookie 保持，退出或会话过期后需重新登录。
- **后续方向**：账号与作品运营数据、平台全量历史作品同步、图片社媒发布、多用户与权限管理、更多生成能力。
