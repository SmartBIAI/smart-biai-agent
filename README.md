# BIAI Agent

**Smart BIAI OpenAPI 自托管接入示例**

BIAI Agent 把查询海外社媒账号、生成视频、编辑发布文案和安排发布串在同一个 Web 工作台里。开发者可以先用模拟数据跑通流程，再用自己的 Smart BIAI 凭证连接真实服务。也可以参考项目代码，将账号查询、视频生成和发布接入自己的应用。

**[在线体验 BIAI Agent](https://developer.biaibiai.com/smart-biai-agent/)**。打开即用，支持模拟查询账号、视频生成和发布排期，体验记录保存在当前浏览器。

## 两分钟试用

安装 **Node.js 22.13 或更新版本**，在项目目录运行：

```sh
npm ci
npm start
```

Windows PowerShell 如限制运行 `npm.ps1`，使用 `npm.cmd ci` 和 `npm.cmd start`。打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，在右上角选「模拟模式」。模拟流程无需 API 密钥；OSS 文件服务使用阿里云 SDK。

1. 点「查询社媒账号」，查看模拟账号和授权状态。
2. 点「生成 AI 视频」，获取模拟报价，再确认生成并播放示例视频。播放需要浏览器能够访问示例视频地址。
3. 点「准备发布」，选择账号并编辑标题。可以立即发布，也可以选择预约时间。
4. 在「发布任务」跟踪进度。进入「生成记录」查看模型、时长，并在弹窗播放视频。

## 连接真实服务

在「连接设置」填入下表中的信息，也可复制 [配置模板](doc/.env.example) 为 `doc/.env.local` 后填写。真实和模拟模式的生成及发布记录各自保存。

| 服务 | 所需信息 |
| --- | --- |
| Smart BIAI 社媒 | App ID、Access Token，以及账号查询和发布权限 |
| Smart BIAI 视频生成 | API Key，以及当前应用可用的 Seedance 2.0 Mini 或 Lite 模型 |
| 对话 AI | DeepSeek 或豆包二选一，填写该服务的 API Key 和模型 ID |

切到「真实模式」后，可以输入「查询 TikTok 账号」或「生成一条 6 秒的竖屏马克杯短片」。生成按实时报价确认，发布需另外确认账号、标题和时间。只有状态为「已授权」且仍可用的账号可以发布。预约任务在工作台运行时到点提交给 Smart BIAI，实际公开时间取决于平台的处理进度。切换回模拟模式后，已确认的真实预约仍会在后台执行。

## 接入范围与数据

- **账号和发布**使用 Smart BIAI 社媒 OpenAPI 查询授权账号、提交视频链接和查询发布状态。账号作品页展示通过本工作台发布完成的作品。
- **视频**使用 Smart BIAI 视频 OpenAPI 获取模型、报价、创建生成任务及查询结果。浏览器直接播放生成服务返回的链接；本地保存任务、链接和有效期等元数据。封面使用生成结果提供的地址，缺失时留空，能否发布取决于平台要求。
- **对话附件**可从本机选择图片、视频或音频上传。已发送的附件可以从历史对话下载。在「连接设置」选择本地文件服务器或阿里云 OSS 后，生成报价时可以给所选素材准备限时链接。[参考素材部署说明](doc/部署说明.md#参考素材文件服务)
- **Agent**使用所选 DeepSeek 或豆包理解用户指令并起草文案。真实生成和发布须分别确认。已发送的对话和其中的草稿保存在本地，点击「历史对话」可继续查看；模拟与真实模式的历史分开保存。
- **部署**由一个 Node.js 进程运行 Web 和后台任务，SQLite 保存任务。本机默认监听回环地址，正式 Docker 部署提供独立访问账号密码和 HTTPS 子路径配置。
