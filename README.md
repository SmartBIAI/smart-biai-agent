# Smart BIAI Agent

基于 **Smart BIAI OpenAPI** 的开源 AI 创作与海外社媒工作台。部署在自己的电脑或服务器上，通过对话查询社媒账号、生成图片和视频、准备发布文案，并在确认后立即或定时发布视频作品。

[在线体验](https://developer.biaibiai.com/smart-biai-agent-static/) · [Smart BIAI 官网](https://www.biaibiai.com/) · [社媒运营 API 文档](https://developer.biaibiai.com/global-social-docs) · [图片与视频生成 API](https://developer.biaibiai.com/docs) · [版本说明](CHANGELOG.md)

无需 API 密钥即可打开在线体验，使用示例账号、视频素材和作品记录熟悉流程。在线体验中的生成与发布均为模拟，记录保存在当前浏览器。部署自己的工作台并配置 API 凭证后，即可使用真实的 AI 生成和社媒发布服务。

当前应用版本：**v0.3.5**。更新内容见 [版本说明](CHANGELOG.md)，首次使用可从 [快速开始](#快速开始) 入手。

## 适合谁使用

- 海外内容创作者：在同一对话中完成创意描述、图片与视频创作、预览和视频发布。
- 品牌与跨境电商团队：上传产品参考素材，制作产品图、海报和短视频，管理已接入的海外社媒账号。
- 开发者：以开源工作台为基础，接入 Smart BIAI OpenAPI，扩展自己的创作与发布流程。

## 功能介绍

### BIAI Agent：在对话中完成创作与发布

- **多轮对话**：结合当前对话中的创作要求和任务进度继续操作，减少重复描述和填写。
- **查询账号与任务**：按平台、国家、名称或账号 ID 查找账号，查询图片、视频和发布记录。
- **继续修改**：沿用已有提示词、参数和附件，调整模型、时长、画幅、清晰度或图片张数，再查看新的生成报价。
- **保留创作版本**：草稿可以持续编辑，重新生成时保留之前的记录，方便回看不同版本。
- **附件复用**：直接上传本地图片、视频或音频，图片显示缩略图；可继续使用原附件、替换附件，或引用已完成的生成结果。
- **历史对话**：新建、切换、恢复历史对话。自托管版本将对话和任务保存到服务器，刷新页面后可继续操作。
- **生成与发布由你确认**：先检查创作参数和费用，再确认生成；发布前另行确认目标账号、文案和时间。

配置 **DeepSeek 或豆包** 并切换真实模式后，即可用自然语言查询、创作和安排发布。模拟模式使用示例数据演示主要流程，方便在接入服务前熟悉操作。

### AI 图片生成

- 支持文字生成图片、参考图创作，以及支持蒙版的模型进行局部编辑。
- 可用于产品使用图、产品海报、社媒配图、插画或视频封面创作。
- 支持 GPT Img / GPT Image 和 Banana 系列，模型列表与可选规格由 OpenAPI 动态读取。
- 一次可生成 **1～8 张**，先查看积分报价和费用上限，再确认生成。
- 根据所选模型设置尺寸、质量、画幅和清晰度，并按对应规格上传参考图或蒙版。
- 在对话中查看结果，点击打开大图或原图，也可在「发布任务 → 图片生成任务」回看历史创作。
- 生成期间显示进度，失败时可查看具体原因；部分成功时可分别查看每张结果及积分结算信息。
- 生成图片由服务保存，工作台记录结果链接和任务信息；在文件保留期内可刷新预览链接。

### AI 视频生成

- 支持文字生成视频、图片参考、视频参考、音频参考，以及模型允许的组合素材输入。
- 支持 Seedance2.0、Seedance2.5 等系列，按模型能力选择画幅、分辨率、时长和声音。
- 支持具备相应能力的首帧、首尾帧、自动时长及尾帧结果选项，切换模型后可按新模型的支持范围调整设置。
- 生成前展示报价，确认后开始生成，进度会自动更新。
- 对话与任务详情均可播放视频，视频生成任务展示模型和时长。
- 失败时可查看服务返回的原因，或刷新任务状态了解最新进展。
- 视频直接使用接口返回的地址，封面使用生成结果返回的地址，缺失时留空；本应用不转存生成视频文件。

### 社媒账号管理与视频发布

- 按平台、国家、自定义标签及名称、别名或 ID 组合筛选账号，平台、国家和标签均可搜索与多选。
- 为账号创建彩色标签，在详情中编辑，或勾选多个账号批量添加、移除；支持“匹配任一”“包含全部”及“未打标签”筛选。
- 标签保存在工作台数据库，按 App ID 和运行模式区分，刷新账号及更新 Access Token 后继续保留。操作说明见 [账号标签与筛选](doc/部署说明.md#社媒账号标签与筛选)。
- 选择视频后准备发布草稿，人工填写或由 AI 建议标题、描述等内容；可修改后再确认。
- 支持**立即发布**和**定时发布**，预约可选择时区。
- 查看账号授权状态，选择已授权且可用的账号发布。
- 视频生成完成后，可直接选择账号准备发布草稿，无需再次上传视频文件。
- 查看已排期、发布中、完成或失败的记录；尚未开始提交的排期可以取消。
- 账号、作品和任务列表支持独立滚动与分批加载，便于浏览较多记录。

### 自动化任务

- 设置单次、每天或每周生成视频的规则，选择时区、生成时间、发布时间和目标账号。
- 每次执行先报价，超过单次积分上限时结束。视频生成成功后先建立发布排期。人工审核模式会等待确认，可在审核时预览、改文案与改期。自动发布模式按已启用的规则发布。
- 可暂停规则、执行一次并跟踪每次生成、审核和发布的结果。真实模式的 BIAI Agent 能理解自然语言，逐轮收集任务参数，补齐后展示可确认的草稿。详见 [自动化任务](doc/部署说明.md#自动化任务)。

### 连接设置与参考素材

| 功能 | 说明 |
| --- | --- |
| 真实 / 模拟模式 | 使用示例数据体验流程，或连接自己的 API 使用真实服务；两种模式分别保存记录 |
| Smart BIAI 社媒连接 | 配置 App ID 与 Access Token，用于账号查询和视频发布 |
| Smart BIAI 生成连接 | 配置应用 API Key，共用于图片和视频生成，按应用授权加载模型 |
| 对话 AI | DeepSeek 或豆包二选一，填写 API Key 和已开通的模型 ID |
| 服务器文件服务 | 将参考素材上传到自己的服务器，通过 HTTPS 链接供生成服务读取 |
| 阿里云 OSS | 也可选择 OSS 保存参考素材，并提供有时效的访问链接 |
| 账号登录 | 提供独立登录页、密码显示切换、保持登录 7 天和退出登录 |
| 数据保存 | 对话、草稿和任务保存在本地数据库，API 凭证加密保存 |

### 对话理解与内容生成

DeepSeek / 豆包负责理解对话、辅助文案和准备草稿，**Smart BIAI 负责图片与视频生成**。两类服务分别配置相应的密钥和模型；对话模型从所选供应商已开通的型号中选择。

## 从创作到发布

1. **连接服务**：在「连接设置」配置所需的 Smart BIAI 凭证和对话 AI，切换到真实模式。
2. **查找账号**：在对话中查询账号，或在「社媒账号」页按国家和平台筛选。
3. **准备创作**：描述图片或视频目标，可附加参考素材；检查 Agent 整理的提示词、模型和参数。
4. **确认生成**：获取报价，核对积分上限，点击确认后才会提交。生成后直接在对话中预览。
5. **继续调整**：结合当前对话提出修改，或点击「调整参数」。保留未要求改变的内容，再次报价与确认。
6. **确认发布**：视频满意后选择已授权账号，检查标题、描述、封面与发布时间，再确认发布。
7. **跟踪任务**：在「发布任务」查看视频生成、图片生成与发布状态；在历史对话中继续处理。

你可以这样表达：“查看美国区 TikTok 账号”、“使用参考图生成两张产品使用图”、“把画幅改成 9:16，保留原来的附件”、“基于刚才的视频准备明天上午的发布草稿”。

## 快速开始

需要 **Node.js 22.13 或更新版本**。

```sh
git clone https://github.com/SmartBIAI/smart-biai-agent.git
cd smart-biai-agent
npm ci
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，选择「模拟模式」即可体验，无需 API 密钥。在 Windows PowerShell 中可使用 `npm.cmd ci` 和 `npm.cmd start`。

服务器安装见 [Docker 部署指南](doc/宝塔Docker首次部署.md)，版本升级见 [部署更新指南](doc/更新说明.md)。工作台登录账号在部署时设置，与 Smart BIAI 官网账户分别管理；服务凭证在「连接设置」中填写。

## 连接真实服务

在「连接设置」填写，也可复制 [环境配置模板](doc/.env.example) 为 `doc/.env.local` 后填写。Docker 使用部署目录中的 `.env`。

| 服务 | 所需信息 | 获取方式 |
| --- | --- | --- |
| Smart BIAI 社媒 | App ID、Access Token、账号查询及发布权限 | [Smart BIAI 官网](https://www.biaibiai.com/) |
| Smart BIAI 生图与视频 | 应用 API Key、相应模型授权与可用积分 | [Smart BIAI 官网](https://www.biaibiai.com/) |
| DeepSeek 或豆包 | 供应商 API Key、已开通的模型 ID，二选一 | 对应供应商控制台 |
| 参考素材服务 | 公网 HTTPS 域名，或 OSS Bucket 与访问凭证 | 自有服务器或阿里云 OSS |

纯文字生成无需准备参考素材文件服务；使用上传附件时，需先配置可被生成服务读取的公网链接。真实生成和对话 AI 调用消耗对应服务额度，费用以实际报价和供应商规则为准。

更多设置见 [使用与配置](doc/部署说明.md)，多轮操作说明见 [Agent 使用说明](doc/Agent使用说明.md)。

## 部署与数据保存

- **运行方式**：基于 Node.js 与 SQLite，可直接运行或通过 Docker 部署，支持配置 HTTPS 域名和访问路径。
- **生成结果**：图片与视频由生成服务保存，工作台记录模型、参数、结果链接和任务信息，预览受源文件保留期限影响。
- **参考附件**：可保存在自己的服务器，或按配置上传到 OSS，再供生成服务读取。
- **备份与迁移**：同时保留数据目录、环境配置和参考附件，具体步骤见部署指南。
- **定时发布**：关闭网页后，运行中的服务仍可处理已确认的排期；请保持服务运行，实际公开时间还受社媒平台处理进度影响。
- **多人使用**：当前工作台使用一个登录账号，登录者共享该部署中的对话、任务和连接设置。
