# 多轮 Agent 使用说明

Smart BIAI Agent 可以结合当前对话中的创作、草稿和任务状态继续操作。无需重复描述所有参数或重新上传仍可用的参考附件，也无需使用固定指令格式。

## 连接与模式

在连接设置中选择 DeepSeek 或豆包，填写已开通的模型 ID 和 API Key，配置 Smart BIAI 服务并切换真实模式。对话理解会消耗所选 AI 服务的额度；图片或视频生成另行报价，并在确认后执行。

离线模拟使用演示数据和有限的指令识别，不调用真实 AI。可以体验查询、草稿、报价和确认，也可以点击生成结果上的“调整参数”复用已有创作。完整多轮语义能力需要真实模式的对话 AI。

## 可以接续的操作

- 结合当前讨论的任务查询真实进度、读取原始参数或查看结果。
- 调整未确认草稿的提示词、模型、数量、画幅、尺寸、质量、时长或声音等参数。
- 对已结束的创作准备新的尝试，沿用未修改的参数与参考素材。
- 明确追加、替换或移除附件，或将已完成且链接有效的结果用于后续创作。
- 为可用视频准备发布草稿，选择已授权账号，修改文案、时区和立即或定时发布安排。

Agent 会先解析操作对象和需要改变的内容，再读取任务、检查能力、准备草稿或报价。多条记录都符合描述时会询问；缺少必要信息或模型不可用时也会要求补充，不会猜选另一条任务或未授权模型。

## 参数和素材如何保留

选择已有任务作为来源时，参数从实际任务记录读取。未要求修改的提示词、张数和附件默认保留；切换模型后按新模型能力校验规格，必要的适配会显示在草稿中。明确要求但不受支持的参数会报出问题，不会静默忽略。

参考附件通过本地文件 ID 关联。报价时由文件服务重新准备可读取链接，不直接沿用上次请求中可能已过期的签名地址。原文件缺失、蒙版不兼容或素材数量超限时，需要重新上传或明确选择如何调整。

新尝试有新的草稿和任务编号，原始成功、失败、结算或退款记录继续保留。修改尚未确认的草稿会更新当前卡片并获取新报价。

## 确认与状态限制

Agent 的工具不具备提交生成或发布的权限。准备好草稿后，用户仍需检查参数、附件和报价，点击“确认生成”或发布确认按钮。报价到期或参数、凭证发生变化时，需要重新报价。

生成中、审核中或受理结果不明的任务不能直接创建重试；应先查看原任务的状态，避免重复扣费。已确认且尚未结束的发布任务不能通过修改草稿假装修改原任务。尚未提交的本地预约可在任务页取消后重新准备；已经发送的平台任务能力以 OpenAPI 为准。

发布账号须处于已授权且可发布状态。预约使用明确的时区和时间，不允许预约到过去、视频过期之后或时区切换中的歧义时间。

## 对话恢复和范围

会话保存用户与助手消息、任务引用和草稿。服务端另行保存操作观察、目标备忘及尝试的来源关联，刷新或恢复历史后仍可接续。任务状态、费用和模型能力以服务端最新记录和实际接口为准，备忘不会覆盖这些事实。

默认只使用当前会话已关联的记录。需要其他记录时，先明确查询工作区记录，再选择目标。并发打开同一对话时，版本不一致的修改会要求刷新；同一轮请求重放不会重复插入草稿。

## 开发者扩展

`agent.mjs` 定义工具目录、上下文和执行边界，`integrations.mjs` 负责 DeepSeek / 豆包的规划协议，服务端负责持久化、任务读取、报价和并发检查。新增能力应注册工具并补充参数、状态与权限校验；无需新增用户指令关键词。

目前的工具覆盖任务读取、任务查询、模型目录、账号查询、生成草稿、重新报价和发布草稿。工具执行结果会作为观察返回给 AI，AI 据此继续规划或向用户回复。规划轮数和工具调用数有上限，无法完成时保留已准备的草稿并说明下一步，不无限循环。

旧版接口和离线演示保留兼容识别逻辑；使用新版界面的真实模式走 `agent.v1` 工具协议。
