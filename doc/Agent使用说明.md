# 多轮 Agent 使用说明

Smart BIAI Agent 可以结合当前对话中的创作要求、草稿和任务进度继续操作。你可以沿用之前的参数与参考附件，修改后再确认生成或发布。

## 连接与模式

在「连接设置」选择 DeepSeek 或豆包，填写已开通的模型 ID 和 API Key，配置 Smart BIAI 服务后切换真实模式。凭证获取与配置步骤见 [使用与配置](部署说明.md#配置-api-服务)。

对话理解会消耗所选 AI 服务的额度；图片或视频生成单独展示积分报价，确认后才会开始生成。

模拟模式无需密钥，可用示例数据体验查询、草稿、报价、确认和结果预览。使用自然语言接续多轮创作，需要配置对话 AI 并切换到真实模式。

## 可以接续的操作

- 查询当前讨论的任务进度，查看原有参数或生成结果。
- 查询本地账号标签，按平台、国家、标签及账号名称组合查找账号。标签可匹配任一或全部，也可查找未打标签的账号。
- 调整未确认草稿的提示词、模型、数量、画幅、尺寸、质量、时长或声音等参数。
- 基于已经完成或失败的创作重新准备草稿，沿用未修改的参数与参考素材。
- 追加、替换或移除附件，或将已完成且链接有效的结果用于后续创作。
- 为可用视频准备发布草稿，选择已授权账号，修改文案、时区和立即或定时发布安排。

你可以直接说明希望继续哪一次创作、修改哪些内容，也可以点击生成结果上的「调整参数」。例如：“沿用刚才的参考图，换一个模型，改成两张。”这些是表达示例，可以按自己的习惯描述。

如果有多条记录符合描述，Agent 会请你选择；缺少必要信息或所选模型不可用时，会提示需要补充或调整的内容。

## 参数和素材如何保留

基于已有任务继续创作时，未要求修改的提示词、张数和附件默认保留。切换模型后，工作台会检查新模型支持的规格，并在草稿中显示需要调整的内容。

仍保存在服务器上的参考附件可以继续复用，报价时会重新准备可供生成服务读取的链接。如果原文件已删除、蒙版不兼容或素材数量超限，页面会提示重新上传或调整附件。

重新生成会保留之前的任务、结果及结算记录，便于比较不同版本。修改尚未确认的草稿时，当前卡片会更新，并按新参数获取报价。

## 生成与发布确认

准备好草稿后，请检查参数、附件和报价，再点击「确认生成」。视频生成完成后，可先预览，再选择账号、检查文案和时间，单独确认发布。报价到期，或参数、连接配置发生变化时，需要重新获取报价。

任务仍在生成、审核或等待服务确认时，请先查询原任务进度，避免重复生成和扣费。任务失败后，可查看具体原因，再调整参数准备新的生成。

尚未提交的定时发布可在任务页取消，再准备新的发布安排。已经提交到社媒服务的任务需要继续查询状态，编辑草稿不会改变已提交的内容。

发布账号需已授权且可用。定时发布请选择未来的时间和明确的时区，并确保视频在发布时仍可读取；如遇夏令时切换，请核对实际执行时刻。

## 历史对话与任务

自托管工作台会保存对话、草稿和任务关联。刷新页面或恢复历史对话后，可以继续查看和修改。任务进度、费用与可用模型会按服务的最新结果显示。

Agent 默认结合当前对话中的记录操作。需要使用其他历史任务时，可以先请它查询任务，再选择要继续的记录。多个页面同时编辑同一对话时，如提示内容已更新，请刷新后继续。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 换模型后仍要修改参数？ | 不同模型支持的尺寸、画幅和素材数量可能不同，请按草稿提示调整后重新报价。 |
| 之前的附件无法复用？ | 检查原文件是否仍在服务器上，文件服务或 OSS 是否可用；必要时重新上传。 |
| 生成失败后如何继续？ | 查看错误详情，确认任务已结束后，基于原任务调整参数或模型，再确认生成。 |
| 想接着另一个对话的任务操作？ | 打开对应历史对话，或先查询任务并明确选择目标。 |

更多操作见 [使用与配置](部署说明.md)，安装与升级见 [Docker 部署指南](宝塔Docker首次部署.md) 和 [部署更新指南](更新说明.md)。

账号标签在「社媒账号」页维护，操作步骤见 [账号标签与筛选](部署说明.md#社媒账号标签与筛选)。标签用于分类，账号能否发布仍取决于授权和服务状态。
