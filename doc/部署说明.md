# BIAI Agent 部署说明

## 运行要求

- Windows、macOS 或 Linux，安装 Node.js 22.13 或更新版本。项目使用 Node.js 自带的 HTTP 服务和 SQLite，阿里云 OSS 接入使用官方 SDK。
- 运行账号需要对数据目录有读写权限。真实模式要求服务器能够访问 Smart BIAI 和所选 AI 服务，浏览器能够访问返回的视频源地址。
- 这个版本面向单人使用，只监听 `127.0.0.1`。应用没有独立的用户登录和权限管理。远程部署通过 SSH 隧道访问，避免把应用端口直接暴露到公网或局域网。

## 本机启动

在项目目录执行：

```sh
node --version
npm ci
npm start
```

Windows PowerShell 如果限制运行 `npm.ps1`，执行 `npm.cmd ci` 和 `npm.cmd start`。打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)，先用模拟模式试走一遍。命令窗口关闭或使用 `Ctrl+C` 后，工作台和后台任务都会停止。

启动端口使用进程环境变量 `PORT`，默认为 `4173`。`BIAI_DATA_DIR` 指定数据库目录，默认为项目下的 `.data/`。这两个变量在启动进程前设置。

Windows PowerShell 示例：

```powershell
$env:PORT = '4180'
$env:BIAI_DATA_DIR = 'D:\biai-agent-data'
npm.cmd start
```

macOS 或 Linux 示例：

```sh
PORT=4180 BIAI_DATA_DIR="$PWD/.data" npm start
```

端口更改后，访问 `http://127.0.0.1:4180/`。新进程要复用原来的任务和已保存密钥，请沿用原数据目录。

## 启用真实模式

1. 在 [Smart BIAI 官网](https://www.biaibiai.com/) 获取或申请社媒 App ID 和 Access Token、视频生成 API Key。确认应用有账号查询和发布权限，并已开通 Seedance 2.0 Mini 或 Lite。
2. 为 DeepSeek 或豆包准备 API Key 和已开通的模型 ID，两者选其一。
3. 在工作台「连接设置」填写，或将本目录的 [`.env.example`](.env.example) 复制为 `doc/.env.local` 后填写。前者的密钥会加密写入本机数据库，后者在服务器端读取。
4. 切换右上角的「真实模式」。依次验证账号列表、Agent 指令、视频报价。再按需要确认实际生成，并选定测试账号预览、确认发布。

| 配置项 | 用途 |
| --- | --- |
| `BIAI_SOCIAL_APP_ID` / `BIAI_SOCIAL_ACCESS_TOKEN` | 社媒服务 App ID 和 Access Token |
| `BIAI_VIDEO_API_KEY` | 视频生成 API Key |
| `BIAI_AI_PROVIDER` | `deepseek` 或 `doubao` |
| `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` | 选择 DeepSeek 时填写 |
| `ARK_API_KEY` / `DOUBAO_MODEL` | 选择豆包时填写 |

设置页保存的连接信息优先，其次读取进程环境变量和 `doc/.env.local`。同一项配置建议使用一个来源，便于排查密钥更新。状态轮询无需配置回调地址或回调密钥。

## 远程服务器

将已审核的源码放到服务器，用普通系统用户运行。执行 `npm ci` 安装依赖，再执行 `npm start`。从你自己的电脑建立 SSH 隧道：

```sh
ssh -N -L 127.0.0.1:4173:127.0.0.1:4173 USER@SERVER
```

将 `USER@SERVER` 替换为服务器的登录用户和地址，保持隧道运行，再在本机浏览器打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。若改端口，应用端与隧道两端统一使用新端口。

Linux 长期运行可交给 systemd。在 `/etc/systemd/system/biai-agent.service` 保存以下示例，替换 `User`、`WorkingDirectory`、数据目录和 Node.js 的绝对路径。确认运行用户能读取源码和本地配置，并能写入数据目录。

```ini
[Unit]
Description=BIAI Agent
Wants=network-online.target
After=network-online.target

[Service]
Type=simple
User=biai
WorkingDirectory=/opt/biai-agent
Environment=PORT=4173
Environment=BIAI_DATA_DIR=/var/lib/biai-agent
ExecStart=/usr/bin/node /opt/biai-agent/server.mjs
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now biai-agent
sudo systemctl status biai-agent
```

通过 `sudo journalctl -u biai-agent -n 50` 查看启动日志。通过 SSH 隧道访问时，断开浏览器或隧道不会停止由 systemd 管理的服务。

## 参考素材文件服务

在「连接设置 → 参考素材文件服务」选一种方式。对话先把原文件上传到工作台。真实生成时，点「准备素材并报价」才会给选中的文件准备 24 小时下载链接。选择 OSS 时，这一步会把这些文件上传到你配置的 Bucket。

### 本地文件服务器

填写可从公网访问的 HTTPS 域名，例如 `https://media.example.com`，以及服务器上的绝对附件目录。留空使用数据目录下的 `uploads/`。也可设置 `BIAI_STORAGE_PROVIDER=local`、`BIAI_MEDIA_PUBLIC_ORIGIN` 和 `BIAI_MEDIA_DIRECTORY`。修改目录后，已上传的文件仍从原目录读取。

域名需要解析到有公网入口的服务器，HTTPS 的 443 端口和证书需要可用。Nginx 可以在该域名的 HTTPS `server` 中只转发素材路径，保留 URL 的路径和签名参数：

```nginx
location ^~ /media/ {
    access_log off;
    proxy_set_header Host 127.0.0.1:4173;
    proxy_pass http://127.0.0.1:4173;
}

location / { return 404; }
```

通过隧道或服务器本机访问工作台。附件目录由工作台读取，别把它配置成公开静态目录。工作台核对素材链接的签名及有效期，再返回单个文件。

### 阿里云 OSS

选择「阿里云 OSS」，或设置 `BIAI_STORAGE_PROVIDER=oss`。支持从 `doc/.env.local` 读取 `OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET`、`OSS_BUCKET`、`OSS_REGION` 和可选的 `OSS_ENDPOINT`、`OSS_CUSTOM_DOMAIN`、`OSS_FILE_DIR`、`OSS_SECURITY_TOKEN`。也可在设置页填写，留空的密钥字段保留原值。

密钥需允许在指定对象目录上传和读取文件。Bucket 可以保持私有。默认签名地址使用 OSS 公网域名，配置自定义域名时，该域名需要绑定到同一 Bucket、支持 HTTPS，并将签名参数原样传给 OSS。该模式无需给工作台设置公网域名。参见 [阿里云 OSS 临时授权](https://www.alibabacloud.com/help/en/oss/user-guide/upload-files-using-presigned-urls)。

## 排期、备份与升级

- **定时发布**依赖应用进程。恢复运行后，错过时间不超过 15 分钟的待发布任务会尝试补交，超过窗口的会标为「已错过」。请在停机或更换密钥前先查看待发布任务。与旧密钥绑定的真实任务在恢复原连接后才会继续处理。
- **备份**先停止应用，再复制整个数据目录，包括 SQLite 文件、`uploads/` 附件目录以及隐藏的 `.credentials-key`、`.media-link-key`（如存在）。自定义附件目录和 `doc/.env.local` 需要另行备份。数据库包含历史对话、草稿和任务。限制备份访问权限。
- **升级**先停止服务并备份，然后更新源码、运行 `npm ci`，沿用原数据目录并重启。恢复备份时先关闭服务，整目录恢复后再启动，避免把旧数据库和新加密密钥混用。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 页面打不开 | 确认服务已启动。若端口已被占用，换一个端口并按新地址访问。远程访问还需检查 SSH 隧道。 |
| 真实模式无法读取账号 | 核对 App ID 与 Access Token 是否配套，并确认账号查询和发布权限。 |
| 无可用视频模型 | 检查视频 API Key 所属应用是否开通 Mini 或 Lite。 |
| Agent 无法理解指令 | 确认 AI 服务、密钥和模型 ID 属于同一供应商，且模型已开通。 |
| 视频无法播放或发布 | 在「生成记录」刷新链接，并检查源文件保留期限。无封面时是否可发由平台决定。 |
| 发布结果待确认 | 先到 Smart BIAI 核对原发布记录。确认原任务结果后再决定是否重新发布。 |
