# 使用与配置

本指南介绍本地运行、API 连接、参考素材和数据管理。服务器安装请参阅 [Docker 部署指南](宝塔Docker首次部署.md)。

## 本地运行

需要 Node.js 22.13 或更新版本，以及访问外部 API 和媒体源地址的网络连接。

```sh
git clone https://github.com/SmartBIAI/smart-biai-agent.git
cd smart-biai-agent
npm ci
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。在 Windows PowerShell 中可使用 `npm.cmd ci` 和 `npm.cmd start`。选择模拟模式即可先熟悉账号查询、生成和发布流程。

服务默认监听本机地址，数据库和附件默认保存在项目的 `.data/` 中。通过启动进程的环境变量可以调整端口和数据目录。

```sh
PORT=4180 BIAI_DATA_DIR="$PWD/.data" npm start
```

Windows PowerShell 示例使用以下设置。

```powershell
$env:PORT = '4180'
$env:BIAI_DATA_DIR = Join-Path (Get-Location) '.data'
npm.cmd start
```

更改端口后按新端口访问，沿用原数据目录可继续读取已有记录。

## 配置 API 服务

可以在「连接设置」填写，也可以将本目录的 [`.env.example`](.env.example) 复制为 `doc/.env.local`。设置页保存的值优先，其次是进程环境变量和本地配置文件。Docker 环境使用 `deploy/.env`，具体步骤见 Docker 部署指南。

| 变量 | 用途 |
| --- | --- |
| `BIAI_SOCIAL_APP_ID` | Smart BIAI 社媒 App ID |
| `BIAI_SOCIAL_ACCESS_TOKEN` | Smart BIAI 社媒 Access Token |
| `BIAI_VIDEO_API_KEY` | Smart BIAI 视频生成 API Key |
| `BIAI_AI_PROVIDER` | `deepseek` 或 `doubao` |
| `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` | DeepSeek 密钥和模型 ID |
| `ARK_API_KEY`、`DOUBAO_MODEL` | 豆包密钥和模型 ID |

Smart BIAI 接入凭证可从 [官网](https://www.biaibiai.com/) 获取或申请。对话 AI 的密钥和模型由对应供应商提供。视频应用需要已开通 Mini 或 Lite 模型。状态查询采用轮询。

切换到真实模式后，先查看账号和模型是否可用。创建视频前查看报价，生成完成后预览。发布草稿需要另外选择已授权账号并确认文案和时间。

## 参考素材文件服务

点击输入框左侧的附件按钮，可上传图片、视频和音频。每条消息最多附加 9 个文件，单个文件最多 100 MB。用于生成时还需符合所选模型的素材要求。

在「连接设置 → 参考素材文件服务」选择本地文件服务器或阿里云 OSS。点击「准备素材并报价」时，应用会为选中的文件准备 24 小时读取链接。

### 本地文件服务器

填写公网 HTTPS 域名，例如 `https://agent.example.com`。附件目录留空时使用数据目录下的 `uploads/`，也可以指定服务器上的绝对目录。修改目录只影响新上传的文件。

| 变量 | 用途 |
| --- | --- |
| `BIAI_STORAGE_PROVIDER` | 填写 `local` |
| `BIAI_MEDIA_PUBLIC_ORIGIN` | 外部服务可以访问的 HTTPS 域名 |
| `BIAI_MEDIA_DIRECTORY` | 附件目录，留空使用默认目录 |

应用通过签名验证和有效期检查提供素材。域名需要能从公网访问，代理需保留请求路径和签名参数。使用 Docker 的子路径配置时，素材链接会自动带上 `BIAI_BASE_PATH`。请按 Docker 指南配置 HTTPS 代理。

### 阿里云 OSS

选择 OSS 后，点击「准备素材并报价」会将选中的附件上传到指定对象目录，再生成限时读取链接。Bucket 可以保持私有，密钥需具备该目录的上传和读取权限。

| 变量 | 用途 |
| --- | --- |
| `BIAI_STORAGE_PROVIDER` | 填写 `oss` |
| `OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET` | OSS 访问密钥 |
| `OSS_BUCKET`、`OSS_REGION` | Bucket 名称和地域，例如 `cn-hangzhou` |
| `OSS_ENDPOINT` | 可选的 OSS 地域 Endpoint |
| `OSS_CUSTOM_DOMAIN` | 可选的 HTTPS 下载域名，需绑定同一 Bucket 并支持签名读取 |
| `OSS_FILE_DIR` | 对象目录前缀 |
| `OSS_SECURITY_TOKEN` | 可选的 STS Token |

配置页的密钥输入框留空会保留已配置的值。签名链接过期后，后续报价会重新准备素材链接。

## 数据、排期和备份

- 对话、草稿、任务和设置保存到数据库，参考附件保存在上传目录。生成视频文件由视频服务保存，预览能力受源文件保留期限影响。
- 页面关闭后，正在运行的服务器会继续处理已确认的任务。停机恢复后，错过时间不超过 15 分钟的预约会尝试补交，超过窗口则显示「已错过」。
- 更换服务密钥可能暂停绑定旧连接的任务。恢复原连接后可继续查询和处理。
- 备份前停止应用，复制整个数据目录及使用的环境配置文件。备份需包含隐藏的 `.credentials-key` 和 `.media-link-key`，以及自定义附件目录。Docker 备份命令见部署指南。

## 构建静态体验版

在项目目录执行以下命令。

```sh
npm run build:demo
```

将 `dist/demo/` 的全部内容复制到静态站点目录，包含 `demo-assets/` 中的视频和封面。例如，上传至 `/opt/smart-biai-agent-demo/` 后，在 Nginx 的 HTTPS 站点配置中加入以下路径。

```nginx
location = /smart-biai-agent-static {
    return 301 /smart-biai-agent-static/$is_args$args;
}

location ^~ /smart-biai-agent-static/ {
    alias /opt/smart-biai-agent-demo/;
    index index.html;
    autoindex off;
    add_header Cache-Control "no-cache" always;
}
```

访问自己的 `https://agent.example.com/smart-biai-agent-static/`。静态体验版在浏览器内运行模拟流程，记录保存在当前浏览器，适合公开展示。更新方式见 [部署更新指南](更新说明.md)。Nginx 示例也见 [`deploy/baota-static-nginx.conf.example`](../deploy/baota-static-nginx.conf.example)。

默认素材是随项目分发的约 4 秒马克杯视频和尾帧封面，由站点自身提供，不依赖第三方样片链接。模拟生成使用固定示例画面，所选提示词、模型和时长只用于流程演示。旧体验记录会自动改用当前示例素材，对话和任务仍保留。

构建时可以使用 `BIAI_DEMO_SAMPLE_VIDEO_URL` 和 `BIAI_DEMO_SAMPLE_COVER_URL` 指定有权公开的 HTTPS 示例素材地址。地址会写入公开页面，请选择长期可公开访问的直链。仅设置封面变量时会替换默认封面；设置外部视频而未设置封面时，封面留空。不要使用短期签名地址。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 页面打不开 | 确认进程已启动，端口与访问地址一致。 |
| 账号读取失败 | 检查 App ID 和 Access Token 是否配套、服务权限是否开通。 |
| 没有视频模型 | 检查应用是否开通支持的 Mini 或 Lite 模型。 |
| Agent 无法解析指令 | 检查 AI 供应商、密钥和模型 ID 是否匹配。 |
| 视频无法播放 | 刷新视频链接，检查源文件期限和媒体网络访问情况。 |
| 发布状态待确认 | 先在 Smart BIAI 核对原任务记录，再决定是否创建新尝试。 |
