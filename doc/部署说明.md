# 使用与配置

本指南介绍本地运行、工作台登录、API 连接、参考素材和数据保存。服务器安装请参阅 [Docker 部署指南](宝塔Docker首次部署.md)，版本升级请参阅 [部署更新指南](更新说明.md)。

## 本地运行

需要 Node.js 22.13 或更新版本，以及访问外部 API 和媒体源地址的网络连接。

```sh
git clone https://github.com/SmartBIAI/smart-biai-agent.git
cd smart-biai-agent
npm ci
npm start
```

打开 [http://127.0.0.1:4173/](http://127.0.0.1:4173/)。在 Windows PowerShell 中可使用 `npm.cmd ci` 和 `npm.cmd start`。选择模拟模式即可先熟悉账号查询、生成和发布流程。

服务默认监听本机地址，数据库和附件默认保存在项目的 `.data/` 中。通过启动进程的环境变量可以调整端口和数据目录。

```sh
PORT=4180 BIAI_DATA_DIR="$PWD/.data" npm start
```

Windows PowerShell 示例使用以下设置。

```powershell
$env:PORT = '4180'
$env:BIAI_DATA_DIR = Join-Path (Get-Location) '.data'
npm.cmd start
```

更改端口后按新端口访问，沿用原数据目录可继续读取已有记录。

## 工作台登录

配置 `BIAI_LOGIN_USER` 和 `BIAI_LOGIN_PASSWORD` 后，工作台显示独立登录页。密码至少 16 个字符。Docker 部署在部署目录的 `.env` 中填写；直接运行 Node.js 时，通过启动进程的环境变量设置。这两项访问配置不会从 API 本地配置文件 `doc/.env.local` 读取。

工作台登录账号在部署时设置，与 Smart BIAI 官网账户分别使用。每个部署使用一个登录账号，登录者共享该工作台的对话、任务和连接设置。

默认登录最长保持 12 小时；勾选「保持登录 7 天」可延长至最多 7 天。右上角可退出登录。修改登录账号或密码并重启服务后，需要重新登录；普通重启可继续使用未过期的登录状态。浏览器需允许本站 Cookie，服务器部署请通过已配置的 HTTPS 域名访问。

登录过期后，重新登录即可继续使用。忘记密码时，在部署环境中修改 `BIAI_LOGIN_PASSWORD` 并重启服务。浏览器使用登录页；脚本调用应用接口可使用 HTTP Basic 认证。

## 配置 API 服务

可以在「连接设置」填写，也可以将本目录的 [`.env.example`](.env.example) 复制为 `doc/.env.local`。设置页保存的值优先，其次是进程环境变量和本地配置文件。Docker 环境使用 `deploy/.env`，具体步骤见 Docker 部署指南。

| 变量 | 用途 |
| --- | --- |
| `BIAI_SOCIAL_APP_ID` | Smart BIAI 社媒 App ID |
| `BIAI_SOCIAL_ACCESS_TOKEN` | Smart BIAI 社媒 Access Token |
| `BIAI_VIDEO_API_KEY` | Smart BIAI 应用 API Key，供图片与视频生成共用 |
| `BIAI_AI_PROVIDER` | `deepseek` 或 `doubao` |
| `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` | DeepSeek 密钥和模型 ID |
| `ARK_API_KEY`、`DOUBAO_MODEL` | 豆包密钥和模型 ID |

Smart BIAI 接入凭证可从 [官网](https://www.biaibiai.com/) 获取或申请。对话 AI 的密钥和模型由对应供应商提供。为应用开通相应图片或视频模型后，工作台会显示可用的生成选项。生成期间，图片每 10 秒、视频每 15 秒自动查询进度，也可手动刷新；连接异常时会延后重试。

两组 API 使用不同凭证和服务地址：社媒查询与发布见 [社媒运营 API 文档](https://developer.biaibiai.com/global-social-docs)，图片与视频生成见 [生成 API 文档](https://developer.biaibiai.com/docs)。仓库内提供社媒文档的 [HTML 文件](global-social-docs.html) 与 [Markdown 源码](SmartBIAI海外社媒运营开放接口文档.md)。

切换到真实模式后，先查看账号和模型是否可用。图片或视频生成前先查看报价，确认后生成并预览。发布视频时需要另外选择已授权账号并确认文案和时间。

### 视频模型

真实模式显示当前应用已授权且可用的视频模型。模型或授权发生变化后，可以刷新或重新打开工作台；新配置通常在一分钟内更新。

模拟模式提供 Seedance2.0、Fast、Mini、Lite、Character、Mono、Seedance2.5 与 Seedance2.5 Flash，方便体验模型选择和参数设置。分辨率、画幅、时长与声音选项随模型变化；真实模式以当前应用的授权和报价为准。完整型号见 [支持的生成模型](../README.md#支持的生成模型)。

### 在 BIAI Agent 生成图片

1. 在「连接设置 → Smart BIAI 图片与视频生成」填写应用 API Key，并开通生图模型。
2. 在对话输入「生成两张简洁的产品海报」，或点击「生成 AI 图片」。可在对话中指定已授权模型名称或完整模型 ID。
3. 编辑提示词，选择模型、生成张数与图片规格。每任务支持 1～8 张。GPT 类使用图片尺寸和质量，Banana 类使用画幅和清晰度。
4. 可先在对话上传 PNG、JPEG 或 WebP 参考图。真实生成前需要配置本地文件服务或 OSS，数量和大小按模型能力校验。支持蒙版的模型可以从已附加的 PNG 中选择蒙版，蒙版需与第一张参考图同尺寸，透明区域为编辑区域。
5. 点击「获取报价」，核对积分上限后点击「确认生成图片」。任务异步执行，结果会回到当前对话。
6. 点击图片查看大图或打开原图。历史图片可在「发布任务 → 图片生成任务」查看，也能通过历史对话恢复。

图片模型按当前应用授权加载，完整型号见 [支持的生成模型](../README.md#支持的生成模型)。如果请求超时，请先刷新原任务状态，避免重复生成。需要自行对接时，可参阅 [图片与视频生成 API](https://developer.biaibiai.com/docs)。

图片可能部分成功，页面会分别展示每张结果及积分结算、退款信息。预览链接有时效，在源文件保留期内可点击「刷新图片链接」。生成图片保存在生成服务，工作台记录结果链接和任务信息。模拟模式使用示例图片，自托管版本会将模拟对话和任务保存到服务器。

图片与视频失败时可查看服务返回的原因和错误码。较长内容显示摘要，鼠标悬浮或键盘聚焦可查看全文；手机可点击查看。详情支持滚动和复制，便于排查问题。点击「刷新状态」只查询原任务，不会重新生成；能否取得最新详情取决于服务是否仍保留任务及原连接是否有效。

## 社媒账号标签与筛选

平台和国家由社媒 API 提供，页面以只读属性显示。国家名称和常见代码会合并为同一选项，例如“美国”“US”“USA”均显示为“美国（US）”；缺失时显示“未知国家”。

标签由工作台保存，用于品牌、产品线、内容方向或运营阶段等自定义分类。

1. 打开「社媒账号 → 管理标签」，填写 1～20 个字符的名称并选择颜色。同一应用内标签名称不能重复，可随时改名或修改颜色。
2. 选择一个账号，在右侧点击「编辑标签」，勾选已有标签或快捷新建，再保存。每个账号最多 10 个标签。
3. 勾选多个账号后，使用「添加标签」或「移除标签」批量操作。表头勾选框选择当前已加载的账号，操作栏会显示所选数量；其他标签保留。
4. 在顶部组合筛选平台、国家、标签与账号搜索。同一平台或国家筛选内匹配任一选项，不同属性之间同时满足。多个标签可选择“匹配任一”或“包含全部”，也可单独查看“未打标签”的账号。
5. 列表默认展示两个标签，点击“＋N”展开；右侧详情显示全部标签。更换筛选条件会清空批量选择，并重新从前 20 条加载。

删除标签前会显示关联账号数量，确认后从这些账号上移除标签，账号和任务继续保留。标签不影响账号授权状态，发布时仍需选择已授权且可用的账号。

标签及账号关联保存在工作台数据库，随完整数据目录备份。真实模式按社媒 App ID 保存，模拟模式单独保存；刷新账号、更换 Access Token 或重启服务后继续保留。切换到其他 App ID 时显示对应应用的标签，切回原 App ID 可继续使用原标签。

配置对话 AI 并使用真实模式后，可以请 BIAI Agent 查询标签或按平台、国家和标签查找账号。标签的创建、编辑和删除在社媒账号页完成；生成与发布仍通过卡片分别确认。

## 自动化任务

1. 打开「自动化任务」，新建规则，填写视频提示词、模型和参数，设置单次生成积分上限。每次执行沿用规则中的视频参数，报价超过上限时会结束本次执行。
2. 选择单次、每天或每周，设置首次生成时间和时区。每周沿用首次生成的星期。发布时间早于生成时间时，安排在次日。
3. 选择已授权的发布账号，填写标题和可选描述。选择「人工审核」或「自动发布」，保存并确认启用。也可以在规则列表确认「执行一次」，本次生成立即加入队列，发布安排在下一次到达的发布时刻。
4. 在「执行记录」查看视频和进度。选择人工审核时，可预览视频、修改文案和发布时间，再确认发布或标记审核不通过。如果原发布时间已过，审核通过时需另选未来的时间。自动发布会在视频可用后按设置安排发布。
5. 在规则列表暂停后，可以编辑规则。暂停停止安排新的执行，已开始的执行可在记录中单独取消。发布已排期后，前往「发布任务」取消尚未提交的排期。

工作台需持续运行。机器恢复后，超过 15 分钟才发现的生成排期会标记为已错过，周期规则继续安排下一次。自动发布如果在计划时刻前未建立排期，也会标记为已错过。服务连接变化后，新的执行需要重新保存规则并检查连接。模拟模式可独立体验整套流程。

真实模式下，在 BIAI Agent 里可以查看规则、准备新建和修改草稿、请求启用、暂停、执行一次或审核。Agent 会打开相应卡片，提交操作前由用户检查并确认。

## 参考素材文件服务

点击输入框左侧的附件按钮，可上传图片、视频和音频。每条消息最多附加 9 个文件，单个文件最多 100 MB。用于生成时还需符合所选模型的素材要求。

在「连接设置 → 参考素材文件服务」选择本地文件服务器或阿里云 OSS。点击「准备素材并报价」时，应用会为选中的文件准备 24 小时读取链接。

### 本地文件服务器

填写公网 HTTPS 域名，例如 `https://agent.example.com`。附件目录留空时使用数据目录下的 `uploads/`，也可以指定服务器上的绝对目录。修改目录只影响新上传的文件。

| 变量 | 用途 |
| --- | --- |
| `BIAI_STORAGE_PROVIDER` | 填写 `local` |
| `BIAI_MEDIA_PUBLIC_ORIGIN` | 外部服务可以访问的 HTTPS 域名 |
| `BIAI_MEDIA_DIRECTORY` | 附件目录，留空使用默认目录 |

应用通过签名验证和有效期检查提供素材。域名需要能从公网访问，代理需保留请求路径和签名参数。使用 Docker 的子路径配置时，素材链接会自动带上 `BIAI_BASE_PATH`。请按 Docker 指南配置 HTTPS 代理。

### 阿里云 OSS

选择 OSS 后，点击「准备素材并报价」会将选中的附件上传到指定对象目录，再生成限时读取链接。Bucket 可以保持私有，密钥需具备该目录的上传和读取权限。

| 变量 | 用途 |
| --- | --- |
| `BIAI_STORAGE_PROVIDER` | 填写 `oss` |
| `OSS_ACCESS_KEY_ID`、`OSS_ACCESS_KEY_SECRET` | OSS 访问密钥 |
| `OSS_BUCKET`、`OSS_REGION` | Bucket 名称和地域，例如 `cn-hangzhou` |
| `OSS_ENDPOINT` | 可选的 OSS 地域 Endpoint |
| `OSS_CUSTOM_DOMAIN` | 可选的 HTTPS 下载域名，需绑定同一 Bucket 并支持签名读取 |
| `OSS_FILE_DIR` | 对象目录前缀 |
| `OSS_SECURITY_TOKEN` | 可选的 STS Token |

配置页的密钥输入框留空会保留已配置的值。签名链接过期后，后续报价会重新准备素材链接。

## 数据、排期和备份

- 对话、草稿、任务和设置保存到数据库，参考附件保存在上传目录。生成视频文件由视频服务保存，预览能力受源文件保留期限影响。
- 页面关闭后，正在运行的服务器会继续处理已确认的任务。停机恢复后，错过时间不超过 15 分钟的预约会尝试补交，超过窗口则显示「已错过」。
- 更换服务密钥可能暂停绑定旧连接的任务。恢复原连接后可继续查询和处理。
- 备份前停止应用，复制整个数据目录及使用的环境配置文件。备份需包含隐藏的 `.credentials-key` 和 `.media-link-key`，以及自定义附件目录。Docker 备份命令见部署指南。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 页面打不开 | 确认进程已启动，端口与访问地址一致。 |
| 账号读取失败 | 检查 App ID 和 Access Token 是否配套、服务权限是否开通。 |
| 没有图片或视频模型 | 检查当前应用是否已授权相应媒体类型的模型，并确认模型已上架。 |
| Agent 无法解析指令 | 检查 AI 供应商、密钥和模型 ID 是否匹配。 |
| 视频无法播放 | 刷新视频链接，检查源文件期限和媒体网络访问情况。 |
| 发布状态待确认 | 先在 Smart BIAI 核对原任务记录，再决定是否创建新尝试。 |
